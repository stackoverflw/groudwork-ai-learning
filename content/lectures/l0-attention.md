## 2 概念逐条


### 缩放点积

定义：注意力先用Q与K的点积求权重，再对V做加权求和。

后果：漏掉缩放会随着头宽增加使logit分布变尖锐，比较时不能只看输出形状。

数学：符号表：Q、K、V为T×D，A=softmax(Q×K转置/sqrt(D))，O=A×V。

工程后果：T=96【估算：本课程示例输入设定】、D=32【估算：验收输入】，CPU即可验证；此实验不含因果mask与多头，不能直接当作自回归推理服务。

常见误解：以为输出与Q同形就正确→实际还要验证权重沿key轴归一化。


### 平方中间量

定义：直接计算注意力分数会产生随序列长度平方增长的中间矩阵。

后果：把上下文加倍可能使分数矩阵增至四倍，KV却只增至两倍。

数学：符号表：分数存储S=T×T×b，缓存存储C=2【估算：按本段符号定义展开】×L×T×H×D×b。

工程后果：单头T=8192【估算：本课程示例输入设定】、FP16【估算：边界输入】的分数矩阵占128MiB【估算：8192×8192×2/2^20】；多头、batch与反向会继续放大，先做分块并逐项预算。

常见误解：以为有KV缓存就没有平方计算→实际prefill与decode的张量形状不同。


### 分块的代价

定义：分块只保留部分分数，降低峰值但需要正确合并归一化统计量。

后果：分别对块softmax再拼接会丢掉全局分母。

数学：符号表：跨块最大值m=max(m_old,m_new)，旧分母必须乘exp(m_old-m)再合并。

工程后果：设块宽256【估算：实验候选】可先在小输入对齐完整实现；本版验收完整CPU实现，不声称实现FlashAttention或给出GPU吞吐。

常见误解：以为分块天然更快→实际小块会增加调度开销，先测再选。

## 4 代码

```python
import numpy as np
def attention(q,k,v):
    s = q @ k.T / np.sqrt(q.shape[-1])
    e = np.exp(s - s.max(-1, keepdims=True))
    return (e/e.sum(-1, keepdims=True)) @ v
r = np.random.default_rng(1)
x = r.normal(size=(7,4))
assert attention(x,x,x).shape == x.shape
```

## 6 三分钟复述稿

注意力有两个矩阵乘法。示例头宽32【估算：实验输入】用于缩放。长序列单头分数矩阵可达128MiB【估算：平方存储公式】。分块候选宽256【估算：实验候选】，合并时要维护全局最大值与分母。
