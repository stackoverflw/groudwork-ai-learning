## 2 概念逐条


### 最大值平移

定义：softmax把每行实数映射为总和为一的非负权重，减最大值保持结果不变。

后果：直接求指数可能溢出；输入1000【估算：溢出示例】时应先减去该行最大值。

数学：符号表：x为输入，m=max(x)，p[i]=exp(x[i]-m)/sum(exp(x-m))。

工程后果：先用CPU float64验证稳定性，再考虑FP16；float64每元素8字节【文献：NumPy dtype itemsize定义】。不要为这个小实验加载GPU模型。

常见误解：以为减最大值改变概率→实际分子分母被同一个因子缩放。


### 归约轴

定义：归约轴决定哪些元素共同归一化；batch维必须保持独立。

后果：全张量归一化会让不同样本互相影响，行和不再满足契约。

数学：符号表：X是B×N，m与分母均保留B×一列；axis=-1【估算：按本段符号定义展开】代表最后一轴。

工程后果：形状256×256【估算：本课程示例输入设定】的float64输入占0.5MiB【估算：256×256×8/2^20】，中间结果必须纳入峰值；验收包含常数行与单元素行。

常见误解：以为只要总和为一就够→实际每一行的和都必须为一。


### 向量化与基线

定义：向量化把Python循环转为数组运算；基线必须在同机同进程测量。

后果：与异机数字比较无法分离硬件、线程和库版本影响。

数学：符号表：S=t_base/t_new，t为相同输入下的中位耗时。

工程后果：先预热2【估算：本课程示例输入设定】次，再重复7次【估算：本课程测量协议】，CPU同步执行，取中位数；目标加速至少1.2倍【估算：课程验收阈值】，并保留正确性门禁。

常见误解：以为越短的单次耗时越可信→实际调度噪声可能主导微秒级结果。

## 4 代码

```python
import numpy as np
def softmax_rows(x):
    z = x - np.max(x, axis=-1, keepdims=True)
    e = np.exp(z)
    return e / np.sum(e, axis=-1, keepdims=True)
assert np.allclose(softmax_rows(np.zeros((2,3))).sum(-1), 1)
```
