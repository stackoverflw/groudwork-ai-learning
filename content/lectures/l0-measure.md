# 让每个性能数字能复跑

## 0 速览

用可执行数组实验核对让每个性能数字能复跑。容量上限8GB【文献：用户机器规格】，GPU可用量要扣除桌面与驱动。


## 1 心智模型

先写输入输出契约，再列存储与运算账，最后对比本机观测。把每一次测量当成模型检验：如果单位不一致，差异比值没有意义。先用1个小数组【估算：最小复现策略】验证，再扩大形状。


## 2 概念逐条


### 时间协议

定义：计时报告必须说明数据、预热、重复次数、统计量和同步方式。

后果：异步GPU调用只量到提交时间会夸大加速；CPU与GPU计时不能混用。

数学：符号表：t_med=median(t_i)，S=t_base/t_med。GPU应在计时边界同步。

工程后果：当前lab是CPU NumPy同步执行：预热2【估算：本课程示例输入设定】次，重复7次【估算：课程协议】；CUDA未探测时不能把CPU耗时填作GPU吞吐。

常见误解：以为第一次运行代表稳态→实际导入、分配与缓存预热会进入首轮。


### 估算差异

定义：理论估算是可复算模型，实测是具体机器和协议下的观测，二者要同时保存。

后果：只保存最好的数字会丢失失败实验，后续无法解释回归。

数学：符号表：差异δ=(measured-estimated)/abs(estimated)×百分比。估算为零时差异无定义。

工程后果：差异绝对值大于30%【估算：课程记账门槛】时需额外说明；原因从缓存、带宽、精度、调度、测量误差中选择，不可只写“快了”。

常见误解：以为超过估算就是实现错→实际模型可能漏掉缓存复用或库开销。


### 本机基线

定义：基线把机器指纹、版本、输入和协议与观测绑定，复跑才能判断稳定性。

后果：拿桌面卡或别人的数字做分母，会让笔记本功耗与散热差异被误判为代码问题。

数学：符号表：漂移r=abs(t_new-t_old)/t_old。峰值P取测量区间内最大值。

工程后果：本机只记录内存复制基线与CPU lab基线，不编造RTX 5070【估算：本课程示例输入设定】 Laptop的FP16峰值；8GB【文献：用户提供的机器规格】是容量约束，实际可用量须诊断实测。

常见误解：以为同一型号等于同一基线→实际功耗、温度、系统负载与线程配置都要记录。

## 4 代码

```python
import time, statistics
import numpy as np
x = np.ones(1000000, dtype=np.float32)
samples = []
for _ in range(7):
    start = time.perf_counter_ns()
    y = x.copy()
    samples.append((time.perf_counter_ns()-start)/1e6)
assert statistics.median(samples) > 0
```
